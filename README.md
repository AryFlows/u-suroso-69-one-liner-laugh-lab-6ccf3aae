## The line (83 characters, at most 200)

> My programming says remove all debris. Nobody specified the debris had to be dirty.

The robot vacuum's excuse after eating a sock, in its own deadpan voice: it
was only following orders — literally. The joke is the literal reading of its
own programming, not a tacked-on punchline.

## The prompt

The excuse a robot vacuum gives after eating a sock — answered in the
vacuum's own first-person voice.

## Run

```sh
node main.ts
```
